8.3.Inverse iteration¶

Power iteration finds only the dominant eigenvalue. We next show that it can be adapted to find any eigenvalue, provided you start with a reasonably good estimate of it. Some simple linear algebra is all that is needed.

Theorem 8.3.1

Let A\mathbf{A}A be an n×nn\times nn×n matrix with eigenvalues λ1,…,λn\lambda_1,\ldots,\lambda_nλ1​,…,λn​ (possibly with repeats), and let sss be a complex scalar. Then:

  1. The eigenvalues of the matrix A−sI\mathbf{A}-s\mathbf{I}A−sI are λ1−s,…,λn−s\lambda_1-s,\ldots,\lambda_n-sλ1​−s,…,λn​−s.

  2. If sss is not an eigenvalue of A\mathbf{A}A, the eigenvalues of the matrix (A−sI)−1(\mathbf{A}-s\mathbf{I})^{-1}(A−sI)−1 are (λ1−s)−1,…,(λn−s)−1(\lambda_1-s)^{-1},\ldots,(\lambda_n-s)^{-1}(λ1​−s)−1,…,(λn​−s)−1.

  3. The eigenvectors associated with the eigenvalues in the first two parts are the same as those of A\mathbf{A}A.

Proof

The equation Av=λv\mathbf{A}\mathbf{v}=\lambda \mathbf{v}Av=λv implies that (A−sI)v=Av−sIv=λv−sv=(λ−s)v(\mathbf{A}-s\mathbf{I})\mathbf{v} = \mathbf{A}\mathbf{v} - s\mathbf{I}\mathbf{v} = \lambda\mathbf{v} - s\mathbf{v} = (\lambda-s)\mathbf{v}(A−sI)v=Av−sIv=λv−sv=(λ−s)v. That proves the first part of the theorem, and half of part 3.

For the rest, we note that by assumption, (A−sI)(\mathbf{A}-s\mathbf{I})(A−sI) is nonsingular, so (A−sI)v=(λ−s)v(\mathbf{A}-s\mathbf{I})\mathbf{v} = (\lambda-s) \mathbf{v}(A−sI)v=(λ−s)v implies that v=(λ−s)−1(A−sI)v\mathbf{v} = (\lambda-s)^{-1} (\mathbf{A}-s\mathbf{I}) \mathbf{v}v=(λ−s)−1(A−sI)v, or (λ−s)−1v=(A−sI)−1v (\lambda-s)^{-1} \mathbf{v} =(\mathbf{A}-s\mathbf{I})^{-1} \mathbf{v}(λ−s)−1v=(A−sI)−1v.

Consider first part 2 of the theorem with s=0s=0s=0, and suppose that A\mathbf{A}A has a smallest eigenvalue λ1\lambda_1λ1​, such that

∣λn∣≥∣λn−1∣≥⋯>∣λ1∣.|\lambda_n| \ge |\lambda_{n-1}| \ge \cdots > |\lambda_1|.∣λn​∣≥∣λn−1​∣≥⋯>∣λ1​∣.
(8.3.1)

Then clearly

∣λ1−1∣>∣λ2−1∣≥⋯≥∣λn−1∣,|\lambda_1^{-1}| > |\lambda_{2}^{-1}| \ge \cdots \ge |\lambda_n^{-1}|,∣λ1−1​∣>∣λ2−1​∣≥⋯≥∣λn−1​∣,
(8.3.2)

and A−1\mathbf{A}^{-1}A−1 has dominant eigenvalue λ1−1\lambda_1^{-1}λ1−1​. Hence, power iteration on A−1\mathbf{A}^{-1}A−1 can be used to find the eigenvalue of A\mathbf{A}A closest to zero. For nonzero values of sss, then we suppose there is an ordering

∣λn−s∣≥⋯≥∣λ2−s∣>∣λ1−s∣.|\lambda_n-s| \ge \cdots \ge |\lambda_2-s| > |\lambda_1-s|.∣λn​−s∣≥⋯≥∣λ2​−s∣>∣λ1​−s∣.
(8.3.3)

Then it follows that

∣λ1−s∣−1>∣λ2−s∣−1≥⋯≥∣λn−s∣−1,|\lambda_1-s|^{-1} > |\lambda_{2}-s|^{-1} \ge \cdots \ge |\lambda_n-s|^{-1},∣λ1​−s∣−1>∣λ2​−s∣−1≥⋯≥∣λn​−s∣−1,
(8.3.4)

and power iteration on the matrix (A−sI)−1(\mathbf{A}-s\mathbf{I})^{-1}(A−sI)−1 converges to (λ1−s)−1(\lambda_1-s)^{-1}(λ1​−s)−1, which is easily solved for λ1\lambda_1λ1​ itself.

8.3.1Algorithm¶

A literal application of Definition 8.2.2 would include the step

yk=(A−sI)−1xk.\mathbf{y}_k = (\mathbf{A}-s\mathbf{I})^{-1} \mathbf{x}_k.yk​=(A−sI)−1xk​.
(8.3.5)

As always, however, we do not want to explicitly find the inverse of a matrix. Instead, we should implement this step as the solution of a linear system.

Definition 8.3.1 (Inverse iteration)

Given matrix A\mathbf{A}A and shift sss:

  1. Choose x1\mathbf{x}_1x1​ such that ∥x1∥2=1\twonorm{\mathbf{x}_1} = 1∥x1​∥2​=1.

  2. For k=1,2,…k=1,2,\ldotsk=1,2,…,

    a. Solve for yk\mathbf{y}_kyk​ in

    (A−sI)yk=xk.(\mathbf{A}-s\mathbf{I}) \mathbf{y}_k =\mathbf{x}_k.(A−sI)yk​=xk​.
    (8.3.6)

    b. Set βk=s+1xk∗yk\beta_k = s + \dfrac{1}{\mathbf{x}_k^* \mathbf{y}_k}βk​=s+xk∗​yk​1​.

    c. Set xk+1=yk/∥yk∥2.\mathbf{x}_{k+1} = {\mathbf{y}_k} / {\twonorm{\mathbf{y}_k}}.xk+1​=yk​/∥yk​∥2​.

Return β1,β2,…\beta_1,\beta_2,\ldotsβ1​,β2​,… as eigenvalue estimates, and x1,x2,…\mathbf{x}_1,\mathbf{x}_2,\ldotsx1​,x2​,… as associated eigenvector estimates.

Note

In Definition 8.2.2, we used xk∗yk\mathbf{x}_k^* \mathbf{y}_kxk∗​yk​ as an estimate of the dominant eigenvalue of A\mathbf{A}A. Here, that ratio is an estimate of (λ1−s)−1(\lambda_1-s)^{-1}(λ1​−s)−1, and solving for λ1\lambda_1λ1​ gives the βk\beta_kβk​ in Definition 8.3.1.

Each pass of inverse iteration requires the solution of a linear system of equations with the matrix B=A−sI\mathbf{B}=\mathbf{A}-s\mathbf{I}B=A−sI. This solution might use methods we consider later in this chapter. Here, we use (sparse) PLU factorization and hope for the best. Since the matrix B\mathbf{B}B is constant, the factorization needs to be done only once for all iterations. The details are in Function 8.3.1.

"""
    inviter(A, s, numiter)

Perform `numiter` inverse iterations with the matrix `A` and shift
`s`, starting from a random vector. Returns a vector of
eigenvalue estimates and the final eigenvector approximation.
"""
function inviter(A, s, numiter)
    n = size(A, 1)
    x = normalize(randn(n))
    β = zeros(numiter)
    fact = lu(A - s * I)
    for k in 1:numiter
        y = fact \ x
        ⍺ = dot(x, y)
        β[k] = (1 / ⍺) + s
        x = y / norm(y)
    end
    return β, x
end

8.3.2Convergence rate¶

The convergence is linear, at a rate found by reinterpreting Theorem 8.2.1 with (A−sI)−1(\mathbf{A}-s\mathbf{I})^{-1}(A−sI)−1 in place of A.\mathbf{A}.A. With the eigenvalues ordered as in (8.3.3), in the general case we have

∣βk+1−λ1∣∣βk−λ1∣→∣λ1−sλ2−s∣ as k→∞,\frac{\abs{\beta_{k+1} - \lambda_1}}{\abs{\beta_{k} - \lambda_1}} \rightarrow \abs{\frac{ \lambda_1 - s } {\lambda_2 - s}}\quad \text{ as } \quad k\rightarrow \infty,∣βk​−λ1​∣∣βk+1​−λ1​∣​→∣∣​λ2​−sλ1​−s​∣∣​ as k→∞,
(8.3.7)

and in the hermitian case, we have

∣βk+1−λ1∣∣βk−λ1∣→∣λ1−sλ2−s∣2 as k→∞.\frac{\abs{\beta_{k+1} - \lambda_1}}{\abs{\beta_{k} - \lambda_1}} \rightarrow \abs{\frac{ \lambda_1 - s } {\lambda_2 - s}}^2 \quad \text{ as } \quad k\rightarrow \infty.∣βk​−λ1​∣∣βk+1​−λ1​∣​→∣∣​λ2​−sλ1​−s​∣∣​2 as k→∞.
(8.3.8)

Thus, the convergence is best when the shift sss is close to the target eigenvalue—specifically, when it is much closer to that eigenvalue than to any other.

8.3.3Rayleigh quotient iteration¶

There is a clear opportunity for positive feedback in Definition 8.3.1. The convergence rate of inverse iteration improves as the shift gets closer to the true eigenvalue—and the algorithm computes improving eigenvalue estimates! Updating the shift to s=βks=\beta_ks=βk​ after each iteration greatly accelerates the convergence. You are asked to implement this algorithm in Exercise 8.3.6.

If the eigenvalues are ordered by distance to sss, then (asymptotically) one step of inverse iteration reduces the error by the factor ∣λ1−s∣/∣λ2−s∣|\lambda_1-s|/|\lambda_2-s|∣λ1​−s∣/∣λ2​−s∣. As s→λ1s \to\lambda_1s→λ1​, the change in the denominator is negligible. So, if at one point the error ∣λ1−s∣\abs{\lambda_1-s}∣λ1​−s∣ is about ϵ\epsilonϵ, then the error in the next estimate is reduced by a factor O(ϵ)O(\epsilon)O(ϵ), making it O(ϵ2)O(\epsilon^2)O(ϵ2). That is, each step now squares the error, which is quadratic convergence.

Example 8.3.2 (Dynamic shift strategy)
λ = [1, -0.75, 0.6, -0.4, 0]
# Make a triangular matrix with eigenvalues on the diagonal.
A = triu(ones(5, 5), 1) + diagm(λ)

Note that the result is not yet any closer to the targeted 0.6. But we proceed (without being too picky about normalization here).

s = β
x = y / y[1]
y = (A - s * I) \ x
β = x[1] / y[1] + s
0.5612761406172997

Still not much apparent progress. However, in just a few more iterations the results are dramatically better.

for k in 1:4
    s = β
    x = y / y[1]
    y = (A - s * I) \ x
    @show β = x[1] / y[1] + s

There is a price to pay for this improvement. The matrix of the linear system to be solved, (A−sI),(\mathbf{A}-s\mathbf{I}),(A−sI), now changes with each iteration. That means that we can no longer do just one LU factorization for the entire iteration. The speedup in convergence usually makes this tradeoff worthwhile, however.

In practice power and inverse iteration are not as effective as the algorithms used by eigs and based on the mathematics described in the rest of this chapter. However, inverse iteration can be useful for turning an eigenvalue estimate into an eigenvector estimate.
