8.2.Power iteration¶

Given that matrix-vector multiplication is fast for sparse matrices, let’s see what we might accomplish with only that at our disposal.

Example 8.2.1 (Power iteration)

Here we choose a magic 5×5 matrix and a random 5-vector.

A = magic(5) / 65;
x = randn(5, 1);

Applying matrix-vector multiplication once doesn’t do anything recognizable.

y = A * x
Loading...

Repeating the multiplication still doesn’t do anything obvious.

z = A * y
Loading...

But if we keep repeating the matrix-vector multiplication, something remarkable happens: Ax≈x\mathbf{A} \mathbf{x} \approx \mathbf{x}Ax≈x.

for j = 1:8
    x = A * x;
end
[x, A * x]
Loading...

This phenomenon seems to occur regardless of the starting vector.

x = randn(5, 1);
for j = 1:8
    x = A * x;
end
[x, A * x]
Loading...

There was a little cheating in Example 8.2.1 to make the story come out neatly (specifically, the normalization step after creating a random matrix). But it illustrates an important general fact that we investigate now.

8.2.1Dominant eigenvalue¶

Analysis of matrix powers is most straightforward in the diagonalizable case. Let A\mathbf{A}A be any diagonalizable n×nn\times nn×n matrix having eigenvalues λ1,…,λn\lambda_1,\ldots,\lambda_nλ1​,…,λn​ and corresponding linearly independent eigenvectors v1,…,vn\mathbf{v}_1,\ldots,\mathbf{v}_nv1​,…,vn​. For our later convenience (and without losing any generality), we assume that the eigenvectors are normalized so that

∥vj∥2=1for j=1,…,n.\twonorm{\mathbf{v}_j} = 1 \quad \text{for } j=1,\ldots,n.∥vj​∥2​=1for j=1,…,n.
(8.2.1)

We also make an important assumption about the eigenvalue magnitudes that will hold for most but not all matrices.

Definition 8.2.1 (Dominant eigenvalue)

If the eigenvalues of a matrix are such that

∣λ1∣>∣λ2∣≥∣λ3∣≥⋯≥∣λn∣,|\lambda_1| > |\lambda_2| \ge |\lambda_3| \ge \cdots \ge |\lambda_n|,∣λ1​∣>∣λ2​∣≥∣λ3​∣≥⋯≥∣λn​∣,
(8.2.2)

then we say that λ1\lambda_1λ1​ is the dominant eigenvalue of the matrix.

In Example 8.2.1, for instance, λ1=1\lambda_1=1λ1​=1 is the dominant eigenvalue.

Now let x\mathbf{x}x be an nnn-vector, let kkk be a positive integer, and refer to (7.2.11):

Akx=VDkV−1x.\mathbf{A}^k \mathbf{x} = \mathbf{V}\mathbf{D}^k\mathbf{V}^{-1}\mathbf{x}.Akx=VDkV−1x.
(8.2.3)

Let z=V−1x\mathbf{z}=\mathbf{V}^{-1}\mathbf{x}z=V−1x, and recall that D\mathbf{D}D is a diagonal matrix of eigenvalues. Then

Akx=VDkz=V[λ1kz1λ2kz2⋮λnkzn]=λ1k[z1v1+z2(λ2λ1)kv2+⋯+zn(λnλ1)kvn].\begin{split} \mathbf{A}^k\mathbf{x} &= \mathbf{V}\mathbf{D}^k \mathbf{z} = \mathbf{V}\begin{bmatrix} \lambda_1^kz_1 \\[0.5ex] \lambda_2^kz_2 \\ \vdots \\ \lambda_n^kz_n \end{bmatrix} \\ &= \lambda_1^k \left[ z_1 \mathbf{v}_{1} + z_2 \left(\frac{\lambda_2}{\lambda_1}\right) ^k \mathbf{v}_{2} + \cdots + z_n \left(\frac{\lambda_n}{\lambda_1}\right)^k \mathbf{v}_{n} \right]. \end{split}Akx​=VDkz=V⎣⎡​λ1k​z1​λ2k​z2​⋮λnk​zn​​⎦⎤​=λ1k​[z1​v1​+z2​(λ1​λ2​​)kv2​+⋯+zn​(λ1​λn​​)kvn​].​
(8.2.4)

Since λ1\lambda_1λ1​ is dominant, we conclude that if z1≠0z_1\neq 0z1​=0,

∥Akxz1λ1k−v1∥2≤∣z2z1∣⏟c2⋅∣λ2λ1∣k⏟r2k∥v2∥2+⋯+∣znz1∣⏟cn⋅∣λnλ1∣k⏟rnk∥vn∥2=∑j=2ncjrjk⋅1→0 as k→∞,\begin{split} \twonorm{ \frac{ \mathbf{A}^k\mathbf{x}}{z_1 \lambda_1^k} - \mathbf{v}_1 } & \le \underbrace{\left|\frac{z_2}{z_1}\right|}_{c_2} \cdot \underbrace{ \left| \frac{\lambda_2}{\lambda_1} \right|^k}_{r_2^k} \twonorm{\mathbf{v}_{2}} + \cdots + \underbrace{\left|\frac{z_n}{z_1}\right|}_{c_n} \cdot \underbrace{\left|\frac{\lambda_n}{\lambda_1}\right|^k}_{r_n^k} \twonorm{\mathbf{v}_{n}} \\[1mm] & = \sum_{j=2}^n c_j r_j^k \cdot 1 \\ & \rightarrow 0 \text{ as $k\rightarrow \infty$}, \end{split}∥∥​z1​λ1k​Akx​−v1​∥∥​2​​≤c2​∣∣​z1​z2​​∣∣​​​⋅r2k​∣∣​λ1​λ2​​∣∣​k​​∥v2​∥2​+⋯+cn​∣∣​z1​zn​​∣∣​​​⋅rnk​∣∣​λ1​λn​​∣∣​k​​∥vn​∥2​=j=2∑n​cj​rjk​⋅1→0 as k→∞,​
(8.2.5)

since, by (8.2.2), rj=∣λj/λ1∣<1r_j = | \lambda_j / \lambda_1 | < 1rj​=∣λj​/λ1​∣<1 for j=2,…,nj=2,\ldots,nj=2,…,n. If we choose x\mathbf{x}x randomly, then the probability that z1=0z_1=0z1​=0 is zero, so we will not be concerned with that case.

Important

If A\mathbf{A}A is diagonalizable and has a dominant eigenvalue λ1\lambda_1λ1​, then Akx\mathbf{A}^k\mathbf{x}Akx asymptotically approaches a scalar multiple of the dominant eigenvector.

Attention

For algorithmic purposes, it is important to interpret Akx\mathbf{A}^k\mathbf{x}Akx as A(⋯A(Ax)⋯ )\mathbf{A}\bigl( \cdots \mathbf{A} (\mathbf{A}\mathbf{x}) \cdots\bigr)A(⋯A(Ax)⋯), i.e., as repeated applications of A\mathbf{A}A to a vector. Doing so allows us to fully exploit sparsity of A\mathbf{A}A, something which is not preserved by taking a matrix power Ak\mathbf{A}^kAk explicitly before the multiplication with x\mathbf{x}x (see Example 8.1.2).

8.2.2Algorithm¶

An important technicality separates us from an algorithm: unless ∣λ1∣=1|\lambda_1|=1∣λ1​∣=1, the factor λ1k\lambda_1^kλ1k​ tends to make ∥Akx∥\|\mathbf{A}^k\mathbf{x}\|∥Akx∥ either very large or very small. In practice, we cannot easily normalize by λ1k\lambda_1^kλ1k​ as we did in (8.2.5), since we don’t know λ1\lambda_1λ1​ in advance.

This issue is resolved by alternating matrix–vector multiplications with renormalizations.

Definition 8.2.2 (Power iteration)

Given matrix A\mathbf{A}A:

  1. Choose x1\mathbf{x}_1x1​ such that ∥x1∥2=1\twonorm{\mathbf{x}_1}=1∥x1​∥2​=1.

  2. For k=1,2,…k=1,2,\ldotsk=1,2,…,

    a. Set yk=Axk\mathbf{y}_k = \mathbf{A} \mathbf{x}_kyk​=Axk​.

    b. Set βk=xk∗yk\beta_k = \mathbf{x}_k^* \mathbf{y}_kβk​=xk∗​yk​. (In the real case, this is βk=xkTyk\beta_k = \mathbf{x}_k^T \mathbf{y}_kβk​=xkT​yk​.)

    c. Set xk+1=yk∥yk∥2\mathbf{x}_{k+1} = \dfrac{\mathbf{y}_k}{\twonorm{\mathbf{y}_k}}xk+1​=∥yk​∥2​yk​​.

Return β1,β2,…\beta_1,\beta_2,\ldotsβ1​,β2​,… as dominant eigenvalue estimates, and x1,x2,…\mathbf{x}_1,\mathbf{x}_2,\ldotsx1​,x2​,… as associated eigenvector estimates.

Tip

The vectors and scalars in Definition 8.2.2 are subscripted by iteration number to help make the discussion here more convenient. In practice, the algorithm can be implemented without keeping the history.

Observe that we can write

xk=(α1α2⋯αk)Akx1,\mathbf{x}_{k} = (\alpha_1 \alpha_2 \cdots \alpha_k ) \mathbf{A}^k \mathbf{x}_{1},xk​=(α1​α2​⋯αk​)Akx1​,
(8.2.6)

where αj=∥yj∥2−1\alpha_j = \twonorm{\mathbf{y}_j}^{-1}αj​=∥yj​∥2−1​ is the normalization factor at iteration jjj. Thus, the reasoning of (8.2.5) implies that xk\mathbf{x}_kxk​ converges to a scalar multiple of the dominant eigenvector v1\mathbf{v}_1v1​ of A\mathbf{A}A. Specifically, suppose that there is some number γ\gammaγ with ∣γ∣=1|\gamma|=1∣γ∣=1 such that

xk−γv1=ϵw, \mathbf{x}_k - \gamma \mathbf{v}_1 = \epsilon \mathbf{w},xk​−γv1​=ϵw,
(8.2.7)

where ∥w∥=1\norm{\mathbf{w}} = 1∥w∥=1 and ϵ≪1\epsilon \ll 1ϵ≪1. Then

βk=xk∗yk=xk∗Axk=(γ‾v1∗+ϵw∗)A(γv1+ϵw)=∣γ∣2v1∗(λ1v1)+O(ϵ)=λ1+O(ϵ).\begin{split} \beta_k &= \mathbf{x}_k^* \mathbf{y}_k \\ &= \mathbf{x}_k^* \mathbf{A} \mathbf{x}_k \\ &= \bigl(\overline{\gamma} \mathbf{v}_1^* + \epsilon \mathbf{w}^*\bigr) \mathbf{A} \bigl(\gamma \mathbf{v}_1 + \epsilon \mathbf{w}\bigr) \\ & = |\gamma|^2 \mathbf{v}_1^* (\lambda_1 \mathbf{v}_1) + O(\epsilon) \\ & = \lambda_1 + O(\epsilon). \end{split}βk​​=xk∗​yk​=xk∗​Axk​=(γ​v1∗​+ϵw∗)A(γv1​+ϵw)=∣γ∣2v1∗​(λ1​v1​)+O(ϵ)=λ1​+O(ϵ).​
(8.2.8)

That is, βk\beta_kβk​ from the power iteration estimates λ1\lambda_1λ1​ about as well as xk\mathbf{x}_kxk​ estimates the dominant eigenvector.

Note

If A\mathbf{A}A is hermitian, then βk\beta_kβk​ equals the Rayleigh quotient RA(xk)R_{\mathbf{A}}(\mathbf{x}_k)RA​(xk​), and, according to Theorem 7.4.4,

βk=λ1+O(ϵ2),\beta_k = \lambda_1 + O(\epsilon^2),βk​=λ1​+O(ϵ2),
(8.2.9)

so the eigenvalue estimate is even better.

function [beta, x] = poweriter(A, numiter)
% POWERITER   Power iteration for the dominant eigenvalue.
% Input:
%   A         square matrix
%   numiter   number of iterations
% Output: 
%   beta      sequence of eigenvalue approximations (vector)
%   x         final eigenvector approximation

    n = length(A);
    x = randn(n, 1);
    x = x / norm(x);
    beta = zeros(numiter, 1);
    for k = 1:numiter
        y = A * x;
        beta(k) = x' * y;
        x = y / norm(y);
    end
end
Important

The only use of A\mathbf{A}A is to find the matrix-vector product Ax\mathbf{A}\mathbf{x}Ax, which makes exploitation of the sparsity of A\mathbf{A}A trivial.

8.2.3Convergence rate¶

While we now feel confident that the sequence {βk}\{\beta_k\}{βk​} converges to the dominant eigenvalue λ1\lambda_1λ1​, we would like to know how fast this convergence is. Looking back at (8.2.4), we know that our normalizations make it so that

xk−γv1=b2(λ2λ1)kv2+⋯+bn(λnλ1)kvn\mathbf{x}_{k} - \gamma \mathbf{v}_1 = b_2 \left(\frac{\lambda_2}{\lambda_1}\right) ^k \mathbf{v}_{2} + \cdots + b_n \left(\frac{\lambda_n}{\lambda_1}\right)^k \mathbf{v}_{n}xk​−γv1​=b2​(λ1​λ2​​)kv2​+⋯+bn​(λ1​λn​​)kvn​
(8.2.10)

for some constants b2,…,bnb_2,\ldots,b_nb2​,…,bn​. If we now make a stronger assumption that λ2\lambda_2λ2​ dominates the rest of the eigenvalues, i.e.,

∣λ1∣>∣λ2∣>∣λ3∣≥⋯≥∣λn∣,|\lambda_1| > |\lambda_2| > |\lambda_3| \ge \cdots \ge |\lambda_n|,∣λ1​∣>∣λ2​∣>∣λ3​∣≥⋯≥∣λn​∣,
(8.2.11)

then expression on the right-hand side of (8.2.10) is dominated by its first term, because

∑j=2nbj(λjλ1)kvj=(λ2λ1)k[b2v2+∑j=3nbj(λjλ2)kvj⏟→0  as k→∞].\sum_{j=2}^n b_j \left(\frac{\lambda_j}{\lambda_1}\right) ^k \mathbf{v}_{j} = \left(\frac{\lambda_2}{\lambda_1}\right)^k \left[ b_2 \mathbf{v}_2 + \underbrace{\sum_{j=3}^n {b_j} \left(\frac{\lambda_j}{\lambda_2}\right) ^k \mathbf{v}_{j} }_{\to 0\, \text{ as } k\to\infty} \right] .j=2∑n​bj​(λ1​λj​​)kvj​=(λ1​λ2​​)k⎣⎡​b2​v2​+→0 as k→∞j=3∑n​bj​(λ2​λj​​)kvj​​​⎦⎤​.
(8.2.12)

Therefore, (8.2.8) now implies that ∣βk−λ1∣|\beta_k - \lambda_1|∣βk​−λ1​∣ is dominated by ∣λ2/λ1∣k|\lambda_2 / \lambda_1|^k∣λ2​/λ1​∣k, which is a case of linear convergence.

Theorem 8.2.1 (Power iteration convergence)

Given (8.2.11), the eigenvalue estimates βk\beta_kβk​ satisfy

∣βk+1−λ1∣∣βk−λ1∣→∣λ2λ1∣as k→∞\frac{\abs{\beta_{k+1} - \lambda_1}}{\abs{\beta_{k}-\lambda_1}} \rightarrow \abs{\frac{\lambda_2}{\lambda_1}} \quad \text{as } k\rightarrow \infty∣βk​−λ1​∣∣βk+1​−λ1​∣​→∣∣​λ1​λ2​​∣∣​as k→∞
(8.2.13)

in the general case, and

∣βk+1−λ1∣∣βk−λ1∣→∣λ2λ1∣2as k→∞\frac{\abs{\beta_{k+1} - \lambda_1}}{\abs{\beta_{k}-\lambda_1}} \rightarrow \abs{\frac{\lambda_2}{\lambda_1}}^2 \quad \text{as } k\rightarrow \infty∣βk​−λ1​∣∣βk+1​−λ1​∣​→∣∣​λ1​λ2​​∣∣​2as k→∞
(8.2.14)

if A\mathbf{A}A is hermitian.

Example 8.2.2 (Convergence of power iteration)

We will experiment with the power iteration on a 5×5 matrix with prescribed eigenvalues and dominant eigenvalue at 1.

ev = [1, -0.75, 0.6, -0.4, 0];
% Make a triangular matrix with eigenvalues on the diagonal.
A = triu(ones(5, 5), 1) + diag(ev);

We run the power iteration 60 times. The best estimate of the dominant eigenvalue is the last entry of the first output.

[beta, x] = poweriter(A, 60);
format long
beta(1:12)
Loading...

We check for linear convergence using a log-linear plot of the error.

err = 1 - beta;
clf,  semilogy(abs(err), '.-')
title('Convergence of power iteration')
xlabel('k'),  ylabel(('|\lambda_1 - \beta_k|'));

The asymptotic trend seems to be a straight line, consistent with linear convergence. To estimate the convergence rate, we look at the ratio of two consecutive errors in the linear part of the convergence curve. The ratio of the first two eigenvalues should match the observed rate.

theory = ev(2) / ev(1)
observed = err(40) / err(39)
Loading...
Loading...

Note that the error is supposed to change sign on each iteration. The effect of these alternating signs is that estimates oscillate around the exact value.

beta(26:29)
Loading...

In practical situations, we don’t know the exact eigenvalue that the algorithm is supposed to find. In that case we would base errors on the final β\betaβ that was found, as in the following plot.

err = beta(end) - beta(1:end-1);
semilogy(abs(err), '.-')
title('Convergence of power iteration')
xlabel('k'),  ylabel(('|\beta_{60} - \beta_k|'));

The results are very similar until the last few iterations, when the limited accuracy of the reference value begins to show. That is, while it is a good estimate of λ1\lambda_1λ1​, it is less good as an estimate of the error in nearby estimates.

The practical utility of (8.2.13) is limited: if we knew λ1\lambda_1λ1​ and λ2\lambda_2λ2​, we wouldn’t be running the power iteration in the first place! Sometimes it’s possible to find estimates of or bounds on the ratio. If nothing else, though, it is useful to know that linear convergence is expected at a rate based solely on the dominant eigenvalues.
